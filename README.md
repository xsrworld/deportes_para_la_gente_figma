# Deporte para la gente

Página principal de una comunidad de fútbol de barrio. Muestra el mensaje de la comunidad, las seis secciones (partidos, jugadores, equipos, torneos, árbitros y canchas) y tarjetas de ejemplo de jugadores y partidos.

> *El fútbol se juega entre todos.*

## Contenido del proyecto

```
deporte-para-la-gente/
├── index.html   Estructura de la página
├── styles.css   Estilos, colores, tipografías y adaptación a móvil
├── script.js    Dibuja la escena en pixel art y los jugadores de las tarjetas
└── README.md    Este archivo
```

## Cómo ejecutarla

1. Descarga o clona la carpeta completa y mantén los tres archivos juntos.
2. Abre `index.html` con doble clic en cualquier navegador (Chrome, Edge, Firefox).
3. Necesitas internet la primera vez para cargar las fuentes de Google Fonts. Sin internet la página funciona, pero con fuentes de respaldo.

No requiere instalar nada ni usar un servidor.

## Tecnologías

- **HTML5:** estructura semántica (`header`, `nav`, `section`, `footer`).
- **CSS3:** variables de color, Grid, Flexbox y *media queries*.
- **JavaScript:** genera el pixel art como SVG dentro de la página.
- **Google Fonts:** Barlow Condensed (titulares) y Space Mono (textos).

## Secciones de la página

| Sección | Qué muestra |
|---|---|
| Encabezado | Logo DG, nombre, eslogan y texto de comunidad |
| Portada | Titular, texto de apoyo, escena en pixel art y marcador |
| Navegación | Las seis secciones numeradas del 01 al 06 |
| Tarjetas | Dos jugadores y dos partidos de ejemplo |
| Cierre | Mensaje «El fútbol nos une» y marca |

## Diseño

| Color | Uso | Código |
|---|---|---|
| Crema | Fondo general | `#f0e4cc` |
| Verde oscuro | Portada y tarjetas de partidos | `#152d22` |
| Verde césped | Detalles y canchas | `#6a9a4f` |
| Naranja | Acentos y pie de página | `#ee7339` |

## Adaptación a dispositivos

- **Computador:** cuatro tarjetas en una fila y seis secciones en una sola línea.
- **Tableta (hasta 1280 px):** dos tarjetas por fila y tres secciones por fila.
- **Celular (hasta 820 px):** todo en una sola columna.

## Accesibilidad

- Los enlaces y tarjetas muestran un contorno naranja al recorrerlos con la tecla Tab.
- Las transiciones se desactivan si el usuario prefiere menos movimiento.
- La ilustración tiene una descripción de texto para lectores de pantalla.

## Alcance de esta entrega

Esta versión incluye solo la **página principal**. Los enlaces de las secciones llevan a puntos dentro de la misma página. Quedan fuera del alcance:

- Registro e inicio de sesión.
- Páginas internas de cada sección.
- Unirse a partidos y reservar canchas.
- Base de datos: los jugadores y partidos son ejemplos escritos en el HTML.
